# 企业微信群机器人 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Agent 绑定企业微信群机器人 Channel，并在对话中通过 `send_to_wecom` 工具将内容推送到绑定的企微群。

**Architecture:** 扩展 `channels` 表支持 `type=wecom` 与 `webhook_url`；`agents` 表增加 `wecom_channel_id` 外键式引用。聊天流程中若 Agent 已绑定有效 Channel，则注册 `send_to_wecom` 工具；工具执行时调用 `portal/internal/channel/wecom.go` 向 Webhook POST 消息。前端 Channel/Agent 表单完成配置。

**Tech Stack:** Go 1.25 / Kratos / GORM / protobuf（`portal`），React 19 / TypeScript / Vite（`web`）。

**Spec:** `portal/docs/superpowers/specs/2026-06-04-wecom-bot-design.md`
