# Fork Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web 可从某条消息 Fork 出独立子会话：拷贝锚点及之前的消息、turn traces、session memory 与 todo，原会话完整保留。

**Architecture:** Portal `ChatService.ForkToMessage` 先做 ACL 校验，再 `db.Transaction` 调用 `data.ForkSnapshot`（事务内 session/message/trace/units repo）。提交后尽力拷贝进程内 todo 并通知 FTS。HTTP 对齐 Rewind：原始 `POST /api/v1/sessions/{id}/fork`，自定义 `ForkResult`，不改 proto / Gateway。权威规格：[2026-09-16-fork-chat-design.md](../specs/2026-09-16-fork-chat-design.md)。

**Tech Stack:** Go（portal `internal/service`、`internal/data`、`internal/server`）、`framework/tool` todo store、`framework/turntrace`、GORM SQLite 单测、Vite/React `web/src`。

```go
type ForkSnapshotInput struct {
	Parent *biz.ChatSession
	Anchor *biz.ChatMessage
}

type ForkSnapshotResult struct {
	Child              *biz.ChatSession
	CopiedMessages     int
	CopiedTraces       int
	CopiedMemoryUnits  int
	CopiedMessageRows  []*biz.ChatMessage // 供 FTS
}

type ForkDeps struct {
	Sessions biz.ChatSessionRepo
	Messages biz.ChatMessageRepo
	Traces   turntrace.Store
	Units    memory.SessionUnitsBackend
}

func ForkSnapshot(ctx context.Context, tx *gorm.DB, in ForkSnapshotInput) (ForkSnapshotResult, error) {
	return ForkSnapshotWithDeps(ctx, tx, in, ForkDeps{
		Sessions: &chatSessionRepo{db: tx},
		Messages: &chatMessageRepo{db: tx},
		Traces:   NewTurnTraceStore(tx),
		Units:    NewSessionUnitsBackend(tx),
	})
}
```

算法：

1. `title := forkSessionTitle(in.Parent.Title)` — `"Fork of "+title`，空标题则 `"Fork"`；按 rune 截断 256。
2. `child, err := deps.Sessions.Create(ctx, in.Parent.UserID, in.Parent.AgentID, title, in.Parent.ID)`。
3. `all, err := deps.Messages.ListActiveOrdered(ctx, in.Parent.ID)`；找 `Anchor.ID` 下标；没有则 error `"fork: anchor not in active prefix"`。
4. 对 `all[:idx+1]` 逐条 `InsertClone(ctx, child.ID, msg)`。
5. `traces, err := deps.Traces.ListBySession(ctx, in.Parent.ID, 0)`；保留 `!CreatedAt.After(anchor.CreatedAt)`；每条浅拷贝后 `SessionID=child.ID`，`RequestID=uuid.NewString()`，`TurnSeq=0`（让 Upsert 重新分配），`Upsert`。
6. `units, err := deps.Units.List(ctx, memory.ListFilter{Scope: memory.ScopeSession, ScopeID: in.Parent.ID, Status: "active", Kind: memory.KindFilterAny})`；对每条 `Remember`：`Scope: memory.ScopeSession`，`ScopeID: child.ID`，`AgentID: in.Parent.AgentID`（不要从 `MemoryHit` 取 AgentID，该结构没有此字段），`Action: ActionAdd`，复制 Content/Metadata。
7. 返回计数。
