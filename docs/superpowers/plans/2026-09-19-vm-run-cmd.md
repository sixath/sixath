# vm_run_cmd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** RCA Agent 可通过 `vm_run_cmd` 对实例 `POST :53000/runCmd` 查看本机日志/进程；危险命令走 terminal 同形确认卡片；空 200 不得当成没日志。

**Architecture:** 框架工具负责策略、查 IP、POST、截断。Portal 在 MySQL 注册之后再挂工具，Lookup 走 `executor.Execute` 固定 SQL。确认用独立 pending store + `chat_stream` 抽取 `Kind=vm_run_cmd`。出网在 **host 已知后** 调 `resolveJaegerClient` 同款 `netx` Client（每请求 `no_proxy`）。

**Tech Stack:** Go `framework/tool` + `executor` + `netx`；Portal `agent_builder` / `rca_builder` / `chat_stream`；Web ToolForm；可选 YAML `rca.vm_run_cmd`。

**Spec:** [docs/superpowers/specs/2026-09-19-vm-run-cmd-design.md](../specs/2026-09-19-vm-run-cmd-design.md)

**钉死：**
- 确认返回必须是 `status=pending` + `token` + `command` + `expires_in`，禁止 `error=confirm_required`。
- `Description` 必填：`"Review the instance command before it is executed."`（Web parser 缺 description 不出卡片）。
- 循环名是 `confirmationRequestsFromResponse`，不是 `collectConfirmations`。
- 自建 pending store，禁止复用 `TerminalPendingStore` 实例。
- HTTP **200** 成功；201–299 也当成功；4xx（除 408/429）`permanent`；408/429/5xx/超时 `transient`。
- 提交仅在用户明确要求时 commit（跳过各 Task 的 commit 步，除非用户说提交）。

- [ ] **Step 3: 实现 POST**

- URL 只拼接 `http://<host>:<port>/runCmd`，port 默认 53000，上限 timeout 120s 默认 30s
- **选 Client（顺序钉死，生产必须能走代理）：**
  1. 若 `ClientForHost != nil` → `c, err := cfg.ClientForHost(host, port)`，err 则 `transient`（包装 `netx.AnnotateError` 若 err 已含代理信息则原样）
  2. 否则若 `HTTPClient != nil` → 用它（单测 `srv.Client()`）
  3. 否则直连 `http.Client{Timeout}`（仅 YAML/测试兜底）
- `Parameters` 对齐 jaeger：`cmd` required；`host`/`vmid`/`port`/`timeout_sec`/`confirm_token` 可选
- 失败 map 含 `http_status`（若已发出 HTTP）与截断正文
- `port` 必须 1–65535，非法 → `permanent`
- body `json.Marshal(map[string]string{"cmd": cmd})`
- 缺 `cmd`，或 `host` 与 `vmid` 都缺 → `permanent`，不发请求
- `host` 与 `vmid` 都有：以 `host` 为准，不查库，结果仍带回 `vmid`
- 2xx：读 body 当 string，截断 `50*1024`，设 `truncated`
- 空 → `output_empty: true`
- `evidence_refs: [{kind: vm_run_cmd, host, vmid}]`
- `ok:false` 用 `rcaErr("vm_run_cmd", msg, code)`
- 有 `url` 键 → permanent 不发请求
- `runCmdHTTPErrorCode(status int)`：408/429/`status>=500` → `ErrorTransient`，其余非 2xx → `ErrorPermanent`
